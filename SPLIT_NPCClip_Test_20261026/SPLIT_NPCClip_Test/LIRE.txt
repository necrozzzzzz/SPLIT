SPLIT — TEST LOCAL DES COLLISIONS NPCCLIP

But : tester le meme BOTREC sur la meme carte, avec les volumes npcclip
neutralises pour les personnages. Ce paquet est un diagnostic sandbox.
Le chargement de l'addon et son effet dans Deadlock restent a verifier.

1. Extraire ce dossier dans SPLIT_v2_new. Fermer completement Deadlock.

2. Dans PowerShell, depuis SPLIT_v2_new :

   py .\SPLIT_NPCClip_Test\preparer_addon.py
   py .\SPLIT_NPCClip_Test\addon.py installer

La preparation ouvre la carte en lecture seule et cree le VPK dans ce dossier.
Elle exige le meme modele physique que celui analyse le 21 octobre 2026.
Si une mise a jour a change ce modele, elle s'arrete avant installation.
Si zstandard est absent : py -m pip install zstandard, puis relancer.
Le chemin Steam par defaut correspond a celui fourni dans la conversation.
Pour une autre installation, le preparateur accepte le chemin du VPK en
argument et addon.py accepte --jeu suivi du dossier game\citadel.

L'installation ajoute UN fichier libre pakNN_dir.vpk dans citadel\addons.
Elle ne remplace aucun addon existant et ne modifie pas gameinfo.gi.
Si le chargement des addons est desactive ou non reconnu, elle s'arrete :
envoyer le message, plutot que modifier des options au hasard.
Garder ce dossier a sa place jusqu'au retrait : il contient installation.json.

3. Relancer Deadlock, ouvrir le sandbox, puis copier le code deja teste :

   Get-Content .\SPLIT_NPCClip_Test\BOTREC_REFERENCE.txt -Raw | Set-Clipboard

Dans la console du jeu, sur une Haze neuve sans objets :

   citadel_hero_testing_enabled 0
   citadel_bot_pasterecording
   citadel_bot_playrecording

Noter si le quatrieme wall jump reussit et si la suite du parcours concorde.
Le debut doit rester conforme au test precedent.
Un echec identique ne suffit pas a invalider l'hypothese tant que le montage
de la ressource modifiee par la carte n'est pas confirme.

4. Fermer Deadlock, puis retirer l'addon apres le test :

   py .\SPLIT_NPCClip_Test\addon.py retirer

Le retrait verifie l'empreinte du fichier avant de le supprimer. Si un autre
outil l'a remplace, il refuse de supprimer ce nouveau fichier.
Pour voir l'etat : py .\SPLIT_NPCClip_Test\addon.py statut
Relancer ensuite Deadlock pour le chargement normal.
Si le test semble corrige, refaire un passage sans addon apres retrait sera
le controle de confirmation avant toute integration dans SPLIT.

PORTEE TECHNIQUE

Une seule ressource : maps/dl_midtown/world_physics.vmdl_c.
La couche npcclip est remplacee par nodraw dans les attributs 6 et 11.
La couche nodraw est absente des filtres de mouvement observes du joueur
et du bot. L'attribut 6 conserve playerclip : les obstacles pour joueurs
restent donc presents. L'attribut 11 etait exclusivement npcclip.
Les donnees binaires des formes physiques, le second buffer KV3 et les
trois autres blocs du modele sont conserves octet pour octet.

Ce changement concerne aussi les autres PNJ et certaines requetes de
collision de la carte. Il est destine a cet essai sandbox puis a etre retire.
Ce n'est pas encore une solution generale pour SPLIT.
Aucune DLL modifiee, aucune injection ni ecriture en memoire du jeu.
Le code BOTREC de reference est celui deja essaye, sans nouvel ajustement.

VERIFICATIONS EFFECTUEES

Verification du hash de la ressource originale ; refus d'une version inconnue.
Verification des buffers et blocs conserves ; aller-retour Zstandard.
CRC32 et index du VPK reconstruit verifies.
Lecture de la ressource modifiee par Source2Viewer CLI 20.1 reussie.
Tests installation/retrait sur dossiers de controle, preservation d'un addon
existant, refus d'un retrait apres remplacement par un fichier different.
Le test d'affichage integral du PHYS depasse la memoire de l'environnement ;
aucune comparaison textuelle integrale independante n'est revendiquee.
Le demarrage et le chargement de ce VPK par Deadlock ne sont pas testes ici.
